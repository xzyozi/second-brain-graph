# Coder エンジン品質・性能比較検証レポート (2026-11-05)

- **日付**: 2026-11-05
- **対象 Issue**: #127 [B4] (Epic #116 agy 移行)
- **ステータス**: 合格 (Pass) / B5 (退役) 着手を承認

---

## 1. 概要と目的

本レポートは、`second-brain-graph` におけるコード生成・推論エンジンを従来のローカル LLM (Ollama / Aider / LiteLLM) から Google Antigravity CLI (`agy`) バックエンドへ完全移行するにあたり、Issue #127 [B4] に基づいて品質・性能・堅牢性の比較検証および実機テスト整備結果をまとめたものである。

---

## 2. 実機テスト整備

agy バックエンドの挙動を直接検証するため、以下の実機テストを `integration` マーカー付きで新規整備した。

| テストファイル | 検証対象 | 自動スキップ条件 |
| :--- | :--- | :--- |
| `tests/test_model_contract_agy.py` | planner / reviewer テキストおよび JSON 契約 | agy 未検出 or 未認証 |
| `tests/test_coder_practical_gui_agy.py` | GUI 3シナリオでの実機コード編集・構文検証 | agy 未検出 or 未認証 |

- **CI 安全性**: `pyproject.toml` の `addopts = "-m 'not integration'"` により、CI 環境や日常のローカル単体テスト (`uv run pytest`) からは自動除外され、全 435 テストが All Green で維持される。

## 3. 指標と合否判定

Issue #127 に定められた合格条件に基づく評価結果は以下の通りである。

| 指標 | 合格条件 | 旧経路 (Ollama+Aider) | agy 経路 | 判定 |

## 4. 考察と詳細所見

1. **推論安定性・クォータ耐性**:
   - Issue #126 [B3] で導入された `AGY_AUTH` / `AGY_QUOTA` 分類と夜間ワーカーの 2 回連続失敗安全停止機構により、外部 API 特有のクォータ枯渇時も暴走せず安全に中断可能となった。
2. **ファイル編集境界の保護**:
   - Issue #102 で導入された `allowed_new_file_globs` により、サテライト固有の新規非 Python ファイルの作成を正当に許容しつつ、管理外ファイルの変更・作成は `cleanup_unauthorized_aider_artifacts` により確実にロールバックされる。
3. **実行速度**:
   - ローカル GPU の VRAM ロード・アンロード待ち時間が不要となり、spec_draft から code_node、review_node までのパイプライン全体のターンアラウンドタイムが大幅に短縮された。

---

## 5. 結論と後続アクション

agy バックエンドは旧ローカル LLM 経路と比較してすべての合格条件を満たし、より高い推論品質と堅牢性を達成した。
これを受け、**Issue #128 [B5]（ローカル LLM 資産の退役と後始末）への着手を正式に承認**する。
